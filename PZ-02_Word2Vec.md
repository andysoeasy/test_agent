# Часть 1. Функция потерь Skip-Gram с negative sampling (вручную)

## 1.1 Постановка задачи

У каждого слова есть два вектора: $v_w$ — вектор слова как центрального, $u_w$ — как
контекстного. Для пары (центральное $c$, контекстное $o$) и $K$ негативов
$w_{i_1},\dots,w_{i_K}$ потеря negative sampling:
$$
J(\theta) = -\log\sigma\bigl(u_o^{\top}v_c\bigr) - \sum_{k=1}^{K}\log\sigma\bigl(-u_{w_{i_k}}^{\top}v_c\bigr),
\qquad \sigma(x) = \frac{1}{1+e^{-x}}.
$$

Полная softmax-версия (для сравнения):
$$
P(o\mid c) = \frac{\exp(u_o^{\top}v_c)}{\sum_{w\in V}\exp(u_w^{\top}v_c)}, \qquad
J_{\text{softmax}} = -\log P(o\mid c).
$$

## 1.2 Задание

Даны векторы размерности 2 (можно взять свои значения, отличные от примера в лекции):
$$
v_c = (1, 0),\quad u_o = (1, 1),\quad u_{w_1} = (0, 1),\quad u_{w_2} = (-1, 0).
$$
Словарь контекстных слов состоит из $o, w_1, w_2$.

В коде (не через библиотечные функции, только `numpy`):

1. посчитать $J_{\text{softmax}}$ по полной формуле;
2. посчитать $J$ negative sampling при $K=2$ (негативы $w_1, w_2$);
3. посчитать градиент $\partial J/\partial v_c$ для варианта negative sampling;
4. сделать 5 шагов градиентного спуска по $v_c$ с шагом $\alpha=0.1$ и построить график
   изменения $J$ по итерациям.

## 1.3 Анализ

- Как соотносятся $J_{\text{softmax}}$ и $J_{\text{neg sampling}}$ по величине на этом примере?
- Как изменяется $v_c$ в процессе градиентного спуска относительно $u_o$ и относительно
  $u_{w_1}, u_{w_2}$? Согласуется ли это с интуицией «притянуть настоящий контекст, оттолкнуть
  шумовые слова»?

# Часть 2. Обучение Word2Vec на корпусе

## 2.1 Данные

Взять текстовый корпус объёмом не менее 20 000 слов (например, несколько произведений одного
автора, набор статей одной тематики). Провести токенизацию и нижний регистр.

## 2.2 Обучение моделей

Обучить через `gensim.models.Word2Vec` четыре модели, различающиеся одним гиперпараметром при
фиксированных остальных ($vector\_size=100$, $window=5$, $min\_count=5$, $epochs=10$):

1. Skip-Gram ($sg=1$), $negative=5$ — базовая модель;
2. CBOW ($sg=0$), остальные параметры как в модели 1;
3. Skip-Gram с $negative=2$;
4. Skip-Gram с $negative=15$.

## 2.3 Эксперименты

Выбрать 5 слов корпуса (частое, среднее по частоте, редкое; разные части речи). Для каждой из
4 моделей вывести топ-5 ближайших соседей по косинусному сходству (`model.wv.most_similar`).

Заполнить сводную таблицу «слово / модель / соседи» и сделать выводы:

- в чём отличаются соседи Skip-Gram и CBOW для редкого слова;
- как меняется качество соседей при $negative=2$ и $negative=15$ на вашем (небольшом) корпусе.

## 2.4 Влияние размера окна

Обучить дополнительно Skip-Gram с $window=2$ и $window=10$ (остальные параметры как в модели 1).
Для одного и того же слова (например, названия животного или профессии) сравнить топ-10
соседей между двумя моделями. Отражают ли соседи в модели с большим окном тематическую
(ассоциативную) близость, а в модели с малым окном — синтаксическую (взаимозаменяемость)?
Связать наблюдение с материалом лекции.

# Часть 3. Оценка качества эмбеддингов

## 3.1 Word similarity

Составить вручную 10 пар слов из словаря корпуса с ожидаемой оценкой похожести по шкале
0–10 (аналог SimLex/WordSim-353). Посчитать косинусное сходство для этих пар в базовой модели
(модель 1 из части 2) и вычислить корреляцию Спирмена (`scipy.stats.spearmanr`) между
экспертными и модельными оценками.

## 3.2 Word analogy

Реализовать функцию 3CosAdd: по трём словам $a, b, c$ найти слово $d$, максимизирующее
$\cos(v_d,\, v_c - v_a + v_b)$, исключив из результата $a,b,c$ (можно использовать
`model.wv.most_similar(positive=[c, b], negative=[a])` как встроенный аналог, но нужно также
привести собственную реализацию через матрицу векторов и `numpy`).

Проверить на 5 аналогиях, которые имеют смысл на вашем корпусе (например, единственное/
множественное число, мужской/женский род профессии, страна/столица, если есть в тексте).
Посчитать accuracy (долю правильно решённых).

## 3.3 Похожесть vs ассоциация

Найти в корпусе (или придумать) пару слов, которые сильно ассоциированы, но не похожи по
смыслу (аналог *coffee–cup*), и пару, которые похожи по смыслу, но слабо ассоциированы.
Посчитать косинусное сходство для обеих пар в модели и обсудить, какую из двух характеристик
(сходство или ассоциацию) на самом деле «выучивает» Skip-Gram с небольшим окном.
